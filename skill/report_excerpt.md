# Skill 技能包使用说明（设计报告可用）

本项目从六级IF–ID–EX0–EX1–MEM–WB处理器的RTL、Block Design、验证脚本和真实修复记录中，提炼了三个可复用Skill，并置于工程根目录的 `skill/`。各Skill包含兼容Agent的SKILL.md、使用条件、具体流程、可复制提示词、自动化脚本和失效边界。

1. **RISC-V自动化验证与测试**：在独立目录对真实RTL执行ALU、寄存器、前递、load-use/save、CSR和复位测试；严格比较写回序列，并复用已有独立参考模型复核全核周期记录。判定同时检查工具退出码、完成标记、断言数量、失败日志和输入哈希，避免“进程退出正常即测试通过”的误判。
2. **Vivado自动化构建与资源分析**：通过MCP只读核对运行工程，提供默认仅生成计划的隔离仿真/综合/实现入口；从原始报告提取LUT、FF、BRAM、DSP、时钟、WNS/TNS等指标，保留报告日期、输入绑定和约束缺口。
3. **RISC-V架构分析与故障排查**：提取XPR/BD/RTL接口清单，以首个分歧周期定位前递优先级、load等待、保存与重复提交、分支/CSR重定向和存储字节选通问题，使用标准提示词形成可验证的最小诊断实验。

使用方法：在项目根目录阅读 `skill/README.md`，用Python3.10以上执行对应脚本；模块仿真需要Icarus或Vivado2026.1的XSim。所有输出使用新目录，原RTL、XDC、测试及报告保持不变。完整重建需在确认耗时后显式使用 `--execute`。

本轮在Icarus和XSim两后端完成四类模块测试，其中契约、前递和CSR测试分别为175、85、230项断言，复位源测试覆盖56项组合。已有ISA、混合与IRQ周期记录使用当前模型重新比对，历史资源/时序报告完成重新提取与617项输入哈希核对。详细结果及判定器负对照见 `skill/evidence/validation.json`。

这些结果分别属于新模块仿真、历史trace重比对和历史报告解析；本轮未重新进行全核仿真、综合、布局布线或板级验收。主核不声明已接入RV32M/TAGE、Cache、DMA或AXI；IO约束、真实桥/中断与板级实测仍需独立验证。一般Skill要求按本地2026AMD指南3.3.5.2组织，最新官方细则、完整协作导出、作品许可证及Gitee发布需在提交前核实完成。
