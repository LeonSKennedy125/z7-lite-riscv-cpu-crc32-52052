# 可直接复制的验证提示词

## 从代码生成有判定能力的测试

```text
请使用 riscv-verification Skill。工程根目录：<填写>；允许的新增输出目录：<填写>。
任务：为<模块或指令>设计并执行最小测试。先读真实RTL、BD接线、原TB和当前契约。
本核为IF-ID-EX0-EX1-MEM-WB；不要假设五级流水、RV32M、Cache或AXI。
只新增测试，不修改现有RTL/XDC/XPR/原TB/golden/历史报告。
请先写独立预期，覆盖正常、边界、相邻依赖和错误路径副作用；区分正向功能与负对照。
短时模块测试可执行；新全核构建或较长工具运行先说明时间并问我。
提交：输入哈希、命令/工具版本、断言数量、退出码、首个失败、日志位置、证据范围。
未执行的步骤明确写未执行；不能用DUT输出反填预期。
```

## 分析写回或周期比对失败

```text
请按 riscv-verification 排查以下最早分歧，不先改期望。
输入：RTL/BD版本=<填写>；测试程序=<填写>；独立参考=<填写>；实际日志/周期CSV=<填写>。
已知：观察阶段=<填写>；是否有load等待/save/flush/CSR redirect=<填写>。
先验证输入完整、计数/完成标记、时钟采样点和输入版本。
逐项比较PC、指令、rs1/rs2/rd、EX0旁路、EX1有效、RAM/MMIO副作用和WB。
输出首个可证实分歧周期、最多三个按证据排序的假设、区分它们的最小实验。
如果仅有寄存器写回trace，只判定寄存器写回；不要据此宣称分支/store/完整退休通过。
```

## 迁移到另一颗 CPU

```text
请提取该Skill可复用的比较器、证据判定和测试矩阵，迁移到<新CPU>。
先给出旧契约与新接口的差异表：流水级、ISA、复位、load延迟、旁路、CSR、观测点和结束条件。
保留通用脚本，替换专用TB与模型适配器，先在新输出目录跑小用例和失败注入。
没有新平台运行证据时只交付适配方案，不能宣称迁移验证通过。
```
